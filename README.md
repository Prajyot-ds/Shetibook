# ShetiBook 🌱 (शेतीबुक)

> **Digital Farming Platform for Indian Farmers**

ShetiBook is a comprehensive digital agriculture assistant designed to empower farmers across India. It provides AI-powered disease diagnosis, multi-language support (English, Hindi, Marathi), verified agricultural vendor contacts, government financial scheme directory, crop encyclopedia, and a farmer community forum.

---

## ✨ Features

- **🔬 Crop Disease Detection**: Upload crop leaf images or describe symptoms with voice or text to diagnose plant diseases and get treatment advice.
- **📚 Crop Encyclopedia**: Detailed information on major crops (grains, vegetables, cash crops, oilseeds) with seasonal timings, soil requirements, and water needs.
- **💰 Government Schemes**: Curated directory of central and state farming assistance schemes (PM-KISAN, PM Fasal Bima Yojana, Kisan Credit Card, etc.) with eligibility and application steps.
- **🛒 Verified Vendors Directory**: Connect directly with verified suppliers for seeds, fertilizers, pesticides, and modern farm equipment.
- **👥 Farmer Community Forum**: Share farming experiences, discuss queries, and connect with other farmers.
- **🤖 Krishi AI Assistant**: Persistent smart chatbot assistant to guide farmers in real-time.
- **🌐 Multilingual & Voice Support**: Switch seamlessly between English, Hindi (हिंदी), and Marathi (मराठी), including voice recognition in regional languages.

---

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js, Express Session
- **Database**: SQLite (via `sql.js`) with automatic seeding
- **Frontend**: Vanilla HTML5, Modern CSS3 (Glassmorphism & responsive layouts), JavaScript (ES6+)
- **Security**: Password hashing with `bcryptjs`
- **File Uploads**: `multer`

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- [Git](https://git-scm.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Prajyot-ds/Shetibook.git
   cd Shetibook
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the server:**
   ```bash
   npm start
   ```

4. **Open in browser:**
   ```
   http://localhost:3000
   ```
